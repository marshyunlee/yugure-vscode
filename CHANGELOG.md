# Changelog

## 0.3.0

Language constants (null, true, false, undefined) are italic and built-in
types are bold, including the semantic tokens for both.

## 0.2.0

Keywords and storage keywords are italic. Operators, built-in types, units,
tags and preprocessor lines stay upright.

## 0.1.0

First release: workbench colors, TextMate token colors and semantic token
colors on the Yūgure palette.
